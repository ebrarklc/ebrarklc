### 📡 RPLIDAR A3M1 — ROS 2 2D SLAM

A hands-on ROS 2 project demonstrating **2D SLAM without wheel encoders or a mobile robot platform**.

Using:

`RPLIDAR A3M1` → `rf2o Laser Odometry` → `slam_toolbox` → `RViz2`

The LiDAR is manually moved through an environment while motion estimation is obtained from LiDAR scans.
